# Интеграция Freedom DEV

## Проверенный контракт

7 ноября 2026 предоставленный пользователем подписанный URL успешно ответил на **GET**, HTTP 200, `application/json`. Запрос содержит `group_id=DEV`. Полный URL хранится только в локальном `.env` как `FREEDOM_API_URL`; его подпись не включается в документацию, тесты, Git или Docker-образ.

Ответ имеет форму:

```json
{
  "error": "",
  "isSuccess": true,
  "data": {
    "dataset_group_id": "DEV",
    "total_records": 1,
    "records": [
      {
        "conversation_id": "synthetic-001",
        "channel": "agent chat",
        "language": "RU",
        "transcript": [
          {"timestamp": "00:02", "speaker": "client", "text": "Синтетический пример"}
        ],
        "audio_url": null
      }
    ]
  }
}
```

Это синтетический пример формата, а не содержимое реального разговора. Клиент проверяет `isSuccess`, отсутствие ошибки, группу DEV и соответствие `total_records` фактическому числу записей. Максимум — 100 записей и 8 МиБ ответа. Поддерживается только наблюдавшийся контракт; неизвестные каналы, языки, участники или несовместимые поля отклоняются до записи в БД.

## Преобразование

| Поле источника | Поле проекта |
|---|---|
| `conversation_id` | `external_id = freedom:DEV:<id>` и `source_metadata.conversation_id` |
| `channel = agent chat` | `channel = chat` |
| `channel = voice call` | `channel = call` |
| `language = RU / KZ / EN` | `language = ru / kk / en` |
| `transcript[].speaker` | `messages[].speaker`, без изменения роли |
| `transcript[].text` | `messages[].text`, с сохранением исходного текста |
| Позиция реплики | `messages[].id`, строковые номера начиная с 1 |
| `timestamp = MM:SS` | `start_ms`; точка отсчёта `conversation_start` |
| `timestamp = ISO 8601` | `start_ms` относительно первой реплики; точка отсчёта `first_message` |
| Исходные `timestamp` | `source_metadata.source_timestamps` по ID реплики |
| Первый абсолютный `timestamp` | `source_metadata.time_origin` |
| `audio_url` | `recording_url` |

Конец реплики не выдумывается: `end_ms = null`. Для абсолютных дат разница переводится в целые миллисекунды с округлением вниз, исходная точность сохраняется в метаданных. Несогласованные форматы времени, отсутствие часового пояса и убывающие таймкоды отклоняются. `audio_alignment_verified = false`: смещение от первой реплики не гарантирует точное позиционирование в аудиофайле. Аудиозаписи не запрашивались и не проверялись на воспроизведение.

## Использование

```powershell
python -m flask --app app:create_app db upgrade
python -m flask --app app:create_app import-dev --dry-run
python -m flask --app app:create_app import-dev
```

`--dry-run` обращается к источнику, проверяет формат и сравнивает данные с БД, но не записывает диалоги. Повторный обычный импорт идентичных данных возвращает `skipped`, а не создаёт копии. Если источник изменил уже загруженный диалог, импорт отменяется целиком: существующие реплики и связанные оценки сохраняются. Изменившаяся ссылка на аудио также считается изменением; автоматической перезаписи нет.

Для повторной проверки сохранённого ответа без сети:

```powershell
python -m flask --app app:create_app import-dev --file database/dev-response.private.json --dry-run
```

Локальный снимок, использованный при первоначальном исследовании, лежит в `database/dev-response.private.json`. Он содержит диалоги и подписанные ссылки на аудио, поэтому исключён из Git вместе с локальной БД; весь каталог `database` исключён из Docker-образа. Команда обычного импорта сама не создаёт новые снимки.

Клиент принимает только HTTPS-адрес Power Platform с `group_id=DEV`, не следует редиректам и не повторяет запрос автоматически. Таймаут сетевых операций — 30 секунд; при чтении проверяется общий лимит времени. Ошибки показывают безопасное описание/HTTP-код без тела ответа и подписанного URL.

Для Docker: `docker compose exec backend flask --app app:create_app import-dev`. Локальная SQLite и PostgreSQL контейнера — отдельные хранилища.

## Результат текущего импорта

- 65 диалогов: 60 чатов, 5 звонков.
- 1268 реплик; 882 относительных таймкода, 386 абсолютных.
- 35 RU, 15 KZ, 15 EN; 5 ссылок на аудио.
- Первый импорт: `imported = 65`, повтор сохранённого ответа: `skipped = 65`.
- Автоматические оценки не создавались: официальный чек-лист в этом API отсутствует.

Публичные методы проекта для чтения данных остаются прежними: `/api/conversations`, `/api/conversations/{id}`, `/api/stats`. Авторизация на стороне прототипа не добавлялась. Подписанные ссылки на записи доступны локальному клиенту в `recording_url` и экспортируемом отчёте, но URL импорта датасета в ответах API проекта отсутствует.
