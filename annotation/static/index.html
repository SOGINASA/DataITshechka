Чек-лист и инструкция

Оценивайте только оператора. Бот, клиент и система дают контекст. Выберите критерий, затем отметьте реплики слева. Для отсутствующего действия задайте проверенный участок. N/A — неприменимо по правилу; «не уверен» — не хватает данных или знаний.

По умолчанию используется официальный чек-лист качества чатов. Шкалы, веса и N/A перенесены из выданного PDF. «Грубые ошибки: Да» означает нарушение и отмечается отдельно от балла. Замена чек-листа создаёт отдельную версию разметки, старые файлы сохраняются. Даже небольшое изменение JSON создаёт новую версию.

Чтобы проверить чужую работу, откройте имя её автора, изучите оценки, исправьте спорное и укажите себя в поле «Проверяющий». Имена здесь — метаданные, входа и проверки личности нет.

Оценки

В режиме дополнения отметка выставляется после подтверждения всех критериев. Изменение оценки снимает её подтверждение. Само открытие записи не отмечает аудио прослушанным.

Данные и разметка остаются на этом компьютере. Изменения записываются на диск только кнопкой сохранения или Ctrl+S. Экспорт содержит тексты диалогов.
