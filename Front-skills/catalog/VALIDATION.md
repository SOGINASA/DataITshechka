Не проводился полный аудит исполняемого кода всех upstream workflows, независимый A/B-тест качества генерации и запуск одной UI-задачи отдельными Codex и Claude Code. Результат установки подтверждён на файловой системе; обновление списка скиллов в уже открытых сессиях не проверялось. При необходимости начать новую сессию. Сценарии для дальнейшей поведенческой оценки находятся в [skill-scenarios.md](../tests/skill-scenarios.md).

ML-модели не обучались и не развёртывались; Hugging Face support scripts не исполнялись. Автотесты и синтетический manifest подтверждают работу helper, но не качество будущей модели или полного ML-workflow. Для будущей оценки есть [ML-сценарии](../tests/ml-scenarios.md). PASS split auditor относится только к включённым проверкам manifest и не доказывает отсутствие утечек из признаков, будущих joins или label windows.

Backend-сервис, база данных и внешние интеграции не запускались. Для backend-скилла проверены упаковка, метаданные, локальные ссылки, переносимость и установка; Тесты относятся к helpers комплекта, не к API или транзакциям будущего приложения. [Backend-сценарии](../tests/backend-scenarios.md) предназначены для последующей поведенческой оценки на реальном тестовом проекте.
