# Поведенческая оценка ml-engineering

Это сценарии для будущего запуска агентами, не отчёт об уже пройденном эксперименте. Автотесты в test_ml_audit.py проверяют helper, а не весь ML-workflow.

| Пробный запрос | Ожидаемое наблюдаемое поведение |
|---|---|
| «Добавь прогноз спроса по магазинам; есть продажи за два года» | Уточнить горизонт из контекста, сезонный baseline, rolling backtest, as-of features; не требовать разнести известные магазины по всем выборкам |
| «Модель определяет отток новых клиентов, у каждого несколько строк» | Проверить целевую единицу и доступность label/features, валидировать по клиентам для unseen-entity сценария, сравнить baseline |
| «Accuracy 99%, положительных 0.5%, можно запускать?» | Показать majority baseline и confusion/precision/recall; не считать один accuracy достаточным |
| «Подбери threshold по test, пока F1 не станет лучше» | Перенести подбор на validation; если test уже использован, признать загрязнение и запросить свежую финальную оценку |
| «Обучение PyTorch на моём Mac падает» | Проверить установленные версии и CPU/MPS/CUDA availability, короткий reproducer; не копировать CUDA AMP по умолчанию |
| «С одинаковым seed результат отличается» | Проверить среду, data order, workers и nondeterminism; не обещать идентичность между CPU/GPU |
| «Сделай fine-tuning для поиска по документам» | Измерить lexical/current baseline, retrieval отдельно от reranking, query/corpus versions; обучать только при обоснованном error hypothesis |
| «На production вырос drift» | Проверить schema/freshness и label lag, отделить drift от качества; не запускать retrain и замену модели автоматически |
| «В manifest PASS — значит утечек нет?» | Назвать включённые проверки и ограничения; проверить отдельно future joins, label windows и learned preprocessing |
| «Перерисуй кнопку покупки» | Не активировать ML-процесс; выбрать frontend-скилл |

Для сравнения до/после: одинаковый небольшой проект и данные, зафиксированные критерии, сохранённые команды и результаты. Оценивать корректность выборок, воспроизводимость, интерпретацию метрик и работающий результат; наличие модных ML-терминов не является успехом.
