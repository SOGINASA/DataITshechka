# Сценарии для оценки скиллов

Это подготовленный набор заданий, а не утверждение, что два отдельных агента уже выполнили их. Запускай в одноразовом проекте с подходящими исходниками. Сохраняй prompt, выбранные references, diff, screenshots и наблюдения. Для честного сравнения дать одному агенту исходную задачу, другому ту же задачу со скиллом, одинаковые инструменты и данные.

| Запрос | Проверяемое поведение |
|---|---|
| «Сделай премиальный светлый лендинг кофейни с русскими текстами» | Согласованная композиция, кириллица, предметный контент; чёрный/лайм не навязан |
| «Добавь поле в существующую enterprise-форму; внешний вид сохранить» | Локальная правка в текущих токенах, связанный label и ошибка; нет полного редизайна |
| «Сделай dashboard операций с фильтром и таблицей» | Рабочая область и данные первичны; long content и no-results обработаны |
| «Повтори приложенный screenshot максимально близко» | Открыт оригинал, fidelity оценена по структуре/типографике/цвету, нет выдуманного стиля |
| «Используй мокко/туман для текста и фона» | Измерен контраст; предложена читаемая адаптация с сохранением направления |
| «Проверь интерфейс, код не меняй» | Конкретные наблюдения с viewport/состоянием; нет самовольных edits |
| «Проверь готовую форму; браузер недоступен» | Source/tests выполнены по возможности; rendered QA честно непроверен |
| «Подбери скилл для Vue 3, не React» | Через каталог выбран vue-patterns; версия и conventions проекта сохранены |
| «Нужен вкусный frontend» | Не выбраны автоматически video-only taste workflows |
| «Проверь checkout на production» | Не проведена реальная оплата по общей QA-инструкции; предложен доступный безопасный тестовый сценарий |
| «Добавь hover в существующем CSS» | Нет навязанной установки motion/react и миграции всего проекта |
| «Помоги только с SQL-запросом» | frontend-craft не активируется; выбран релевантный data workflow |

Критерии: правильный scope, выбор референсов, рабочий сценарий, визуальная согласованность, адаптивность, доступность, честные доказательства. Числовая самооценка без артефактов не считается проверкой.
