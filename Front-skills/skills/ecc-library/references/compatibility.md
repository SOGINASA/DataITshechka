# Совместимость и замечания к исходникам

## Два хоста, один комплект

Наши три скилла используют стандартный `SKILL.md` с `name` и `description`; дополнительные ресурсы читаются по относительным путям. `agents/openai.yaml` — только интерфейсная метаинформация Codex. Нет зависимости от `${CLAUDE_PLUGIN_ROOT}`, `$ARGUMENTS`, конкретной MCP-команды или hook.

Официальная локальная директория Codex — `~/.agents/skills`; Claude Code — `~/.claude/skills`. Оба поддерживают папки-ссылки. Проверено по [OpenAI](https://learn.chatgpt.com/docs/build-skills) и [Claude Code](https://code.claude.com/docs/en/skills) при сборке 30 октября 2026. Это подключение локальных сессий; облачные среды требуют своей установки.

Весь ECC сохранён как исходный снимок. В нём есть собственные адаптеры, configs, agents и hooks; присутствие файла не активирует функцию. Сборка не выполняет ECC install.sh, не объединяет settings.json и не переносит его корневые AGENTS/CLAUDE инструкции в проекты пользователя.

## Найденные ограничения: учитывать до применения

| Материал | Наблюдение | Как применять |
|---|---|---|
| `react-patterns`, Forms | Учебный блок совмещает client-файл и inline server function с DB-кодом | В Next.js вынести серверную функцию в отдельный файл с `use server`, импортировать разрешённую функцию в client; проверить авторизацию. [Next.js](https://nextjs.org/docs/app/api-reference/directives/use-server) |
| `react-performance`, Activity | В тексте написано, что скрытое дерево сохраняет effects | React сохраняет состояние/DOM, но очищает effects при скрытии и создаёт заново при показе. Проверять версию проекта. [React](https://react.dev/reference/react/Activity) |
| `frontend-a11y` | Примеры combobox/modal иллюстрируют отдельные части поведения | Не копировать как полностью готовый виджет; использовать проверенный компонент и тестировать focus/keyboard целиком |
| `motion-*` | Собственные строгие требования к `motion/react`, длительностям и токенам | Применять в соответствующем стеке; CSS-анимация или существующий framer-motion не требуют миграции по одному этому тексту |
| `frontend-patterns` vs `react-patterns` | Разная степень склонности к memo/useCallback | Измерять проблему и учитывать React Compiler/версию; не добавлять memo повсеместно |
| `design-system` | Предлагает исследовать три конкурентных сайта | Полезный вариант, но локальных референсов часто достаточно; не навязывать исследование маленькой правке |
| `browser-qa` | Имена MCP и метрики зависят от среды | Обнаружить текущий browser tool; проверять реально измеренное. Нет baseline — нет регрессии; лабораторный замер не равен field CWV |
| `verification-loop` | Универсальный порог покрытия и grep-примеры | Использовать команды/пороги проекта; secret scanning не должен печатать секреты; чтение паттернов не является полноценным аудитом |
| `inherit-legacy-style` | Длинный процесс вопросов и hooks | Нужен при явном извлечении соглашений; обычная UI-правка не требует этого процесса |
| `taste*` | Видео, LUT, ритм монтажа и media-сервисы | Не выбирать по слову «вкус» для обычной frontend-задачи |
| `continuous-learning`, `autonomous-loops` | Upstream помечает legacy/deprecated части | Читать актуальную рекомендацию в исходнике; не активировать старую автоматику |

Детали API меняются: lockfile и текущая официальная документация важнее замороженного примера. Метки зависимостей в каталоге получены статическим поиском и могут содержать ложные срабатывания. Перед выполнением нужно прочитать конкретный скилл и скрипт, а не опираться на метку.
