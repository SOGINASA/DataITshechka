## Адаптация к UI

Выбери пару под задачу, затем назначь роли surface/text/accent/on-accent. Пара может отлично работать для крупных цветовых плоскостей и не подходить для мелкого текста. Мокко/туман, scarlet/steel и teal/coral нельзя автоматически принимать за текстовые комбинации AA; таблица показывает фактические значения. Добавь подходящий нейтральный текст, а не меняй весь бренд без причины.

Для проверки конкретной пары из корня скилла:

```sh
python3 scripts/contrast.py '#232329' '#B8A7F0'
```

Для полупрозрачного текста/фона сначала вычисли итоговый цвет на реальной подложке или проверь в браузере. Скрипт не принимает alpha и не подтверждает соответствие всей страницы. [Порог контраста текста W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
