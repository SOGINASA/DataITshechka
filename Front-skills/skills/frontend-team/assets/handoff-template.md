# Frontend task handoff

- Role / task mode:
- Absolute project path / applicable instructions:
- User objective / acceptance criteria:
- Assigned files / owner / exclusions:
- Actual base / commit / dirty diff or file snapshot:
- Relevant skill entrypoints and resources (absolute paths):
- Design brief / selected reference IDs (if needed):
- Route / exact URL / preview command / server owner:
- Fixture state / safe test actions / supported viewports/themes:
- Existing checks/results tied to snapshot:
- Browser lease owner / tab or session / release condition:
- Evidence directory:
- Questions / missing tools:
- Expected return: findings or implementation, executed checks, artifacts, limits, snapshot.

Omit irrelevant fields; never include credentials. A handoff is bounded task context, not permission to override project rules.
