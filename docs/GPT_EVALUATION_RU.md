# Полный DEV-прогон через GPT API

Команда запуска из корня репозитория в PowerShell:

```powershell
.\backend\.venv\Scripts\python.exe -u scripts/run_gpt_evaluation.py --run-dir data/runs/gpt-5-mini-full-v2
```

Ключ читается из корневого `.env`: `GPT_API_KEY` (также поддерживается `OPENAI_API_KEY`). Значение ключа не передаётся в аргументах команды и не записывается в артефакты. Дополнительные зависимости не требуются: используется Python standard library и существующий python-dotenv.

Выбранная пользователем модель — `gpt-5-mini`, фиксированный snapshot `gpt-5-mini-2025-08-07`. Для другой модели используйте `--model MODEL_ID`, `GPT_MODEL` или `OPENAI_MODEL`. Приоритет: аргумент, `.env`, значение по умолчанию. Настройка локальной Ollama не меняется.

## Что проверяется

Все 65 диалогов и 520 меток из неизменяемого `dev-reviewed-v1`; исходные тексты, полные чек-листы, исходный prompt `cqa-rubric-v3`. API получает только текстовый контекст и критерии. Эталонные ответы и аудиозаписи не передаются. Для сопоставимости используется прежняя политика voice-v1; новое правило N/A для незаписанного приветствия не подменяет старый эталон внутри эксперимента.

Responses API вызывается с `store=false`, строгой JSON Schema и лимитом 12000 выходных токенов, включая reasoning. Reasoning effort остаётся значением API по умолчанию. Настройка фиксируется в manifest. Ссылки на реплики, статусы и баллы проверяются тем же кодом, что у локальной версии. Итоговый балл считает Python. Общая схема ссылок вынесена в `$defs`, чтобы длинные звонки не превышали ограничение на повторяющиеся enum.

Сначала выполняется один настоящий запрос. Только после структурно корректного ответа начинается обработка остального набора, до трёх запросов одновременно (`--workers 1` для последовательного режима). Автоматических повторов платных запросов нет. При HTTP-ошибке новые запросы не отправляются; уже отправленные запросы сохраняются по завершении.

## Артефакты

В указанной папке, игнорируемой Git:

- `run.json`: модель, параметры, хеши кода и входов; `code/`: снимок кода.
- `requests.json`: точные запросы без ключа; `references.json`: отдельные эталоны.
- `predictions.json`, `responses/`: проверенные решения и финальные ответы API без скрытых рассуждений.
- `metrics.json`: точность по критериям, языкам и каналам, N/A, критические ошибки, MAE итогового балла, задержки и расход токенов.
- `status.json`: завершённость, число сохранённых записей, остановка из-за API.
- `comparison-with-qwen.json`: создаётся после обработки всех 65 записей при наличии полного прежнего прогона Qwen. Скрипт проверяет полное совпадение входов, чек-листов и эталонов; MAE дополнительно считает на общей паре диалогов с итоговым баллом.

`--resume` продолжает только запуск с теми же входами, кодом и параметрами. Уже сохранённые ответы, включая ошибки, не запрашиваются повторно. Для повторной попытки после исправления ключа/квоты используйте новую папку. `--prepare-only` создаёт и проверяет артефакты без обращения к API.

Ошибки и `needs_review` остаются в знаменателе метрик. Незавершённый прогон не позволяет сделать итоговое сравнение. Это DEV с подтверждённой AI-предразметкой, а не независимый тест; соответствие объяснений смыслу цитируемых реплик требует проверки человеком.

## Попытка 7 ноября 2026

`data/runs/gpt-5-mini-full-20261107`: первый запрос вернул HTTP 429. Диагностический повтор подтвердил `type=insufficient_quota`, `code=credit_balance_exhausted`. Причина — исчерпанный баланс кредитов API. Успешных ответов нет; остальные 64 диалога не отправлялись. Для полного прогона нужен ключ проекта с доступным балансом. После пополнения используйте команду выше с новой папкой.

Документация OpenAI: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-5 Mini](https://developers.openai.com/api/docs/models/gpt-5-mini).
